# 非臨床検証計画

## 検証段階

1. 卓上試験: 合成CT画像と単一操作者で基本機能を確認する。
2. 環境試験: 手術室相当の照明、手袋、術衣、マスク、複数人、遮蔽物、反射で評価する。
3. 模擬手術: 臨床ワークフローを再現し、既存操作への切替を含めて評価する。
4. 院内審査用評価: 医療安全、臨床工学、IT、法規担当が証跡をレビューする。

## 必須シナリオ

- 操作者以外が手を動かす。
- 器具やスタッフがカメラ前を横切る。
- 手袋の色、照明、姿勢、利き手が変わる。
- ジェスチャー途中で手を引く。
- センサーが切断される。
- WindowsまたはCTビューアーが応答しない。
- 対象外アプリが前面に出る。
- 同一操作を長時間保持する。
- 通常操作へ即時切替する。

## 記録する指標

- 意図しないコマンド数／時間
- ジェスチャー別の成功率、見逃し率、誤分類率
- エンドツーエンド遅延と最大遅延
- 操作完了時間
- 代替操作への切替時間
- 操作者の負担、理解度、疲労、信頼度

## 合格基準

具体的な数値は臨床責任者と医療安全部門が危害分析に基づいて承認する。開発者だけで決定しない。
