# IT・セキュリティ設計方針

## 配布

- 未署名EXEの手渡し配布を行わない。
- PCコンポーネントが必要な場合は、コード署名されたMSIXまたは病院標準の管理方式を使用する。
- Intune、Configuration Manager、許可リスト等でバージョンを固定・追跡する。

## ネットワーク

- 既定はローカル処理とする。
- 外部クラウド、個人Microsoftアカウント、個人スマートフォンへの依存を避ける。
- 通信が必要な場合は院内ネットワーク分離、相互認証、暗号化、証明書更新を設計する。

## エンドポイント

- 操作対象を指定CTビューアーへ限定する。
- 任意キー列、PowerShell、コマンドプロンプト、アプリ起動を許可しない。
- USB HIDを使う場合は、デバイスID許可、物理管理、BadUSB対策を行う。
- Bluetoothを使う場合は、病院ポリシー、干渉、再接続、なりすまし、電池切れを評価する。

## ログ

- 記録対象: 起動、終了、受付状態、認識分類、出力コマンド、エラー、構成版。
- 記録禁止: 患者氏名、患者ID、CT画像、手術映像、生音声。
- 保存期間と閲覧権限は病院の規程に従う。
