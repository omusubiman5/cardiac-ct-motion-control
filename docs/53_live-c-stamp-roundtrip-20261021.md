1. 稼働中Slicer PID130280を最大化。「詳細マウス操作」→「マウス操作へ切替」で入力所有権を明示変更。

3. 「開口 +15°」を1回実行。画面の開口方向15°、同じ仮配置ID、記録0件。
4. 「傾斜 +15°」を1回実行。画面の傾き15°、記録0件。
5. 「確定（操作記録）」で対象・位置・方向・hashの確認ダイアログを読み、Yesを実行。`COMMITTED`、PERFORMED 1件。最初のアクセシビリティ指定クリックはcached stateエラーで実行されず、再観測後の座標クリックで確定。台帳もその時点で初めて1件となった。

## 証跡と判定

`work/c-roundtrip-20261021/before.json` と `after.json` は、それぞれ別の実稼働Slicerプロセス内で取得した観測値。検査スクリプトは `inspect_runtime.py`。自己作成の照合だが、別fixtureではなく実画面操作で作成・保存・復元した実アプリのデータを検査した。第三者独立レビューではない。
