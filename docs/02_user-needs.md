# ユーザーニーズ

## 現時点で確認済み

- 心臓手術中にCT画像操作が円滑にできず、術者または助手の作業が中断される。
- 術者は清潔域を維持したまま画像を操作したい。
- PCへの未署名EXE導入や個別設定は、利用者とIT部門の負担になる。

## 確認が必要な質問

1. CT画像を操作するのは執刀医、助手、臨床工学技士の誰か。
2. 現在使用しているCT／PACSビューアーとWindowsバージョンは何か。
3. 最も頻繁な操作は、送り、戻し、ズーム、パン、ウィンドウレベルのどれか。
4. 操作失敗が許容される時間と、助手へ切り替える手順は何か。
5. 手術室の照明、カメラ配置、手袋、術衣、マスク、遮蔽物の条件は何か。
6. 同時に画角へ入る人数と、操作権限を持つ人をどう識別するか。
7. 音声操作も必要か。必要なら手術室騒音とマスク装着時の認識条件は何か。
8. 病院の端末管理、ネットワーク分離、USB／Bluetooth利用ポリシーは何か。

## 成功の定義（仮）

- 術者が清潔域を離れず、許可された画像操作を完了できる。
- 意図しない操作が、合意した上限を超えない。
- 認識不能時に安全かつ迅速に既存操作へ切り替えられる。
