## 実施条件

- 実Slicer 5.12.3、Pixel 8aの認識アプリ、同じ固定ドックを対象にする。起動・接続・認識入力サイズ・現在の仮C・受付状態を実際に確認してから試験する。
- 通常認識と試験入力を同時に編集へ使わない。通常カメラの観測中は診断TCP接続を開かない。画像再生時はプロジェクトの認識アプリだけを停止し、実クライアント1本で接続する。
- 既存仮Cを取消・確定・再配置せず、方向試験の前後で中心・面・寸法・角度・カメラを照合して戻す。版は過去へ戻さない。終了時は受付停止。
- 保存・取消・復元の破損試験は自作の隔離デモ／試験用台帳で行う。既存台帳や元モデルを上書きしない。患者・CT・カメラ映像を保存／送信しない。画面証跡は操作パネルや合成Cのプレビューに限定する。
- 自作試験は自己検証と表示し、実モデル、実TCP、実画面、本人の実手、継続観測を区別する。模擬接続や手形ラベルから実画面の合格を逆算しない。

## 実施順序と停止条件

T-00で現在地を確認し、計画を保存してから試験する。T-07の通常認識10分を観測しながら、独立したT-01〜03を実行する。次に通常認識を停止し、Slicerを前面にしてT-04〜06、T-08〜09を実行する。実手T-10/11は通常認識を戻してから行う。

長時間観測中も60秒以内に確認結果を伝える。ユーザーが操作を中断した場合、対象が別のウィンドウになった場合、仮CのID／版が想定外に変わった場合は変更入力を止め、復元可能性を確認する。拒否を成功へ読み替えたり、前面・TTL・凍結ゲートを迂回したりしない。

## 記録と総合判定

試験ごとに実施時刻・対象版・入力・検査層・件数／秒数・結果・証跡・限界を記録する。PASS／FAIL／未検収を区別する。静止画反復は独立した実手サンプル数へ換算しない。T-01/02のテスト数を実手成立数にしない。T-07が手なし／停止状態なら、その条件の継続結果に限定する。

自動で実施できる試験を完了してもT-10/11や元のF-01〜09が未解消なら総合合格にしない。既知不合格はdocs/27に維持し、修正版のどの現象が確認できたかをdocs/36とPROJECT_STATUSへ記録する。
