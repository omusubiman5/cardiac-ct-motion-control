# モーション操作アプリ：ユーザーニーズ

更新日: 2026-08-17

## 目的

CMOSカメラで術者の手の動きを認識し、すでに取得済みの心臓3Dデータの表示視点を、術者自身が非接触で操作できるアプリを作る。

## 背景

- 対象はCT撮影、画像再構成、診断、自動計測、治療機器制御ではない。
- 対象は既存3Dビューアに表示された心臓モデルの視点変更である。
- 別の人へ口頭で視点変更を依頼するより、術者が直接操作できる方が共同作業を速く正確にできる可能性がある。
- Windowsやスマートフォンの汎用連携機能には依存せず、ローカルPCとカメラで完結させたい。
- 出力側は既存ビューアのキーまたはマウス操作への割り当てでよい。

## 必要な操作

1. 心臓3Dモデルの回転。
2. 表示範囲の平行移動（パン）。
3. 拡大・縮小（ズーム）。
4. モーション入力の有効／無効切り替え。
5. 必要な場合のみ基準視点へ戻す。

## 明確な対象外

- スライスや動画の送り。
- スライスや動画の戻し。
- 再生、停止、一時停止。
- CT装置、手術機器、生命維持装置、患者監視装置の操作。
- 患者データや3Dデータ自体の変更。
- 任意のWindows操作、アプリ起動、文字列入力。

## PoCで確認したいこと

- 一般的なUSB接続CMOSカメラで手を安定して検出できるか。
- 手の移動を回転、パン、ズームへ自然に割り当てられるか。
- 手の震えを抑えながら、必要な反応速度を得られるか。
- 認識できないときに勝手な入力を発生させないか。
- 既存のマウス操作を残したまま共存できるか。

## 成功条件

- 起動直後はモーション入力が無効である。
- 有効化後、回転・パン・ズームをカメラ映像上で確認できる。
- 対象外ジェスチャーでは入力イベントが生成されない。
- カメラ切断・認識喪失時には新しい入力を生成しない。
- 実入力は明示的な起動オプションと対象ウィンドウ指定がない限り発生しない。
