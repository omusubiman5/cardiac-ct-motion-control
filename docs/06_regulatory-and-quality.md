# 規制・品質計画

## 薬機法上の位置づけ

医療目的を持ち、意図どおりに機能しない場合に患者または使用者の生命・健康へ影響する可能性があるため、プログラム医療機器または医療機器の付属品に該当する可能性がある。早期にPMDAの医療機器プログラム総合相談を利用する。

## 適用を検討する規格・活動

- JIS T 14971: 医療機器リスクマネジメント
- JIS T 2304 / IEC 62304: 医療機器ソフトウェアライフサイクル
- JIS T 62366-1 / IEC 62366-1: ユーザビリティエンジニアリング
- JIS T 81001-5-1 / IEC 81001-5-1: ヘルスソフトウェアのサイバーセキュリティ
- 構成管理、変更管理、問題解決、トレーサビリティ

## 品質ゲート

1. 意図する用途と対象外用途が承認されている。
2. 危害、危険状態、リスクコントロール、残留リスクが追跡されている。
3. 全要求が試験ケースと結果へ追跡できる。
4. 臨床環境を模擬したユーザビリティ評価が完了している。
5. SBOM、脆弱性対応、更新・ロールバック手順が整備されている。
6. 院内審査および必要な薬事手続が完了している。
