## 今回の実装で固定する非臨床規則（W-00）

- 対象登録の根拠はdocs/20「対象表面」の固定シーン`artifacts/slicer/CARTO3_EA_Map_Demo.mrb`と`CARTOmesh_1-OG`。登録候補はこの指定ファイルを隔離Slicerへ読み込んで採取する。現在開いている任意モデルから自動許可を作らない。
- 位置・寸法はRAS世界座標mm、角度はradで保存、UI表示は度。初期基底は正規化法線nに対し`abs(n.z)<0.9`でworld Z、それ以外でworld Xを参照し、`u=normalize(cross(reference,n))`、`v=cross(n,u)`。移動時は旧uを新しい法線の面へ射影し、長さが1e-6を超えれば正規化、退化時は上の初期基底へ戻す。面内角と進行方向は保持する。変更する場合は期待規則と試験を先に更新する。
- 保存はPython floatのJSON往復値を使い、丸めを加えない。表示点と内部点の比較許容誤差は既存の1e-8mmを維持する。基底の退化判定は既存1e-12。これらは非臨床計算・表示の検査値で、医療上の精度閾値ではない。
- RESET_DIRECTIONはOP-009のC方向操作。RESET_VIEWは許可済みの回転・パン・ズームで変更されるカメラ量を、準備時の基準へ戻す複合操作として扱う。C・モデル・台帳へ作用しない。源文とのこの対応を実Slicerのカメラ／C不変検査へ結び付け、名前が同じだけで採用済みとはしない。
- 開始1.5秒・離散保持／解除0.35秒・既存の感度とZoomConfig値を構成へ固定する。実手の結果が出る前に精度・疲労・臨床合格を宣言しない。
