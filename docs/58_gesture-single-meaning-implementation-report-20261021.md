## 残存リスクと次の一手

- **つまみの限定割当**：仮Cがある間つまみは開口方向になるため、その間ハンドでのズーム不可（マウスホイールは有効）。本人承認済みの範囲内
- **親指下の二重文脈**：メニュー内では次へ（末尾で戻る）、メニュー外では仮C取消。ツリーの原文どおりであり、メニュー外で仮Cがなければ無作用
- **実手検収**：代表経路（🤟→メニュー→グー決定、親指上C呼出→照準→グー仮配置→つまみ開口→グー確定→親指下取消）を本人の実Pixelで検収する必要あり
- **配布**：検収後にruntime再構成→署名配布→起動検収が必要。現配布版は旧割当のまま稼働する

全体完成の判定は変更しない（実手検収・署名配布・監査・独立受入は引き続き未達）。
