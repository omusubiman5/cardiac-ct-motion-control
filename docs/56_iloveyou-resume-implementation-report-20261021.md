## 本人原文・計画との対応

原文：「パーで認識→画面外にして→再度操作 が面倒過ぎる」「iloveyouで復帰させたらすぐに作業に移れないか？」「実装計画書MDを作って実装して。その後、実装報告書MDを作って。」

実装前に作成した計画は[docs/55](55_iloveyou-resume-implementation-plan-20261021.md)。要件正本docs/03に本人変更FR-040〜043を追加。従来の明示開始・品質・前面・通信・凍結保護・確定独立の境界は維持した。

## 実装した操作

- 停止→標準ILoveYou（親指・人差し指・小指）を1.5秒保持→受付開始。
- 🤟保持中は移動しない。パーだけでは開始しない。
- 画面内でパー／人差し指／つまみへ変更して0.35秒安定→準備解除。画面外へ手を下げる必要なし。
- 解除フレームでは命令を出さず、その次のフレームから連続操作の基準を設定する。以前の手位置との差を持ち越さない。
- 手なし・不明・複数手・低スコア・離散ジェスチャーは準備を解除しない。切替の安定判定は途中で不明になるとリセット。
- 仮C凍結は既存の明示再開を必要とする。受付開始だけでCを確定・保存・取消しない。
