# C焼き印 操作シナリオ（2026-10-26）

非臨床プロトタイプの手形操作シナリオ。各行は「操作 → 画面の変化 → 失敗した場合」を示す。
仕様の正本は `docs/57_gesture-single-meaning-plan-20261021.md`。手形の意味は一意（どの状態でも同じ意味）。

## 前提

- Slicerが最前面（タイトルバーを一度クリック。前面でないと手形は届くが実行拒否される）
- 認識 `connected`（Slicerドックのステータスバー表示で確認）
- 手をカメラ画角内に保つ。手が切れると仮Cは凍結する

## シナリオ本体

### 0. 受付開始

| 操作 | 画面の変化 | 失敗時 |
|---|---|---|
| 🤟を **1.5秒** 保持 | ステータスが「受付中」になり主メニューが開く | 1.5秒未満で放すと何も起きない。保持バーが伸びているか見る |

### 1. C焼き印を呼ぶ（2通り・どちらでもよい）

| 操作 | 画面の変化 | 失敗時 |
|---|---|---|
| **A: メニューから** — 親指下で「C焼き印」へ → **グー** | 照準モードへ移行 | メニュー中の人差し指は「パン」の意味であり**選択には使えない**（パンが動くだけ。グーが必須） |
| **B: 直接呼出** — メニュー外で **親指上** | 同じく照準モードへ | メニューが開いていると親指上は「前の項目」の意味になる |

### 2. 照準

| 操作 | 画面の変化 | 失敗時 |
|---|---|---|
| **人差し指** を立てて空間を動かす | 指先に照準点が追従する | 照準が出ない＝照準モードに入っていない。1に戻る。手がブレても安定点が保持される |

### 3. 仮配置

| 操作 | 画面の変化 | 失敗時 |
|---|---|---|
| **グー** | 安定点へ仮Cが出る | 人差し指では置けない。グーが必須 |

### 4. 編集（任意・仮Cがある間のみ）

| 操作 | 画面の変化 |
|---|---|
| **つまみ** を左右に動かす | 開口方向が回転する（この間ハンドのズームは停止。マウスズームは有効） |
| **人差し指** で指し直す | 仮Cが安定点へ移動する |
| **3本指** | 方向を初期値へ戻す |
| **パー** | 視点回転（仮Cは動かない） |

### 5. 確定（2段構え・誤発火防止）

| 操作 | 画面の変化 | 失敗時 |
|---|---|---|
| **グー** | 確定確認画面が開く（まだ保存されない） | グーのまま保持し続けても発火しない。一度開く必要がある |
| **手を開いてから、もう一度グー** | 確定実行（記録へ） | 同じグーを見せ続けても2回目は発火しない。ラッチ解放→再提示が必須 |

### 6. 取り消し

| 操作 | 画面の変化 |
|---|---|
| **親指下** | 仮Cを取り消して通常へ戻る |

## 途中で手が切れた場合（凍結）

手が画角から外れて**0.8秒（loss_grace_s）を超える**と仮Cが凍結する。0.8秒未満の一瞬の切れ目（手形切替）は凍結しない。

| 操作 | 画面の変化 | 失敗時 |
|---|---|---|
| **🤟** | 凍結解除 → **そのまま編集に復帰**（メニューは開かない） | その後はシナリオ 4 または 5 から続行できる。確定なら グー→グー |

## 手形まとめ（迷ったらこれだけ）

| 手形 | 意味 |
|---|---|
| 🤟 | 開始／主メニュー／凍結解除 |
| 親指上 | 前へ（メニュー）・C呼出（メニュー外） |
| 親指下 | 次へ・戻る・閉じる・仮C取消 |
| **グー** | **決定 — メニュー選択・仮配置・確認・確定の全て** |
| 人差し指 | 指す（パン・照準・仮C移動）— **置く動作は絶対にできない** |
| パー | 視点回転 |
| つまみ | ズーム（仮C中は開口方向） |
| 3本指 | 初期値へ |
| 2本指 | 無作用 |
| 手なし・不明 | 無操作（フェイルクローズ） |

## よくある誤解（実測で確認済み）

- 「メニューでCに人差し指」→ **パンになる**。選択はグー（実測：view_pan 190件送信）
- 「人差し指で仮置き」→ **できない**。仮置きはグー
- 「グー1回で確定」→ **できない**。グー→確認画面→グーを下げて→グー
- 「手が一瞬切れると凍結」→ **0.8秒未満は凍結しない**（手形切替の隙間は安全）
- 「凍結したら終わり」→ **🤟で即復帰**。マウス不要
