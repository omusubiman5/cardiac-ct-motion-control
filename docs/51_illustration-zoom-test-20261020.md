# 動く手イラストによるズーム試験（2026-10-20）

本人原文「お前がやれよ。手のイラストで反応しないかな？」に対応。

## 結果

生成イラストの実MediaPipe推論と、その結果を再生した実SafetyController／OperationController→実TCP→試験用Slicerで、開始・メニュー選択・拡大・縮小が成立した。自己作成の入力・試験器・期待値による自己検証。実手、Pixel撮影経路、通常デモの操作成立の証明ではない。

|親指上|22/22をthumbと分類|

## 試験の範囲

既存の生成図docs/images/hand-menu-guide-2026-10-12-v2.pngとview-menu-test-guide-2026-10-12.pngから手を切り出し、1280×720白背景に配置して鏡像化。つまみは画像上で100画素上下に平行移動させ、各フレームを実GestureRecognizerへ入力した。座標を手で作ったり、推論された手形を期待値に差し替えたりしていない。

画像の推論は先にまとめて実行し、その推論座標・手形・信頼度を約50ms間隔で再生した。カメラのリアルタイム撮影から描画までの一括試験ではない。実Slicerは球体のみの別プロセス、ポート18983、試験専用IPCとwork内台帳を使用。通常デモのポート18944には接続していない。前面条件は実条件のまま、テスト画面の前面化だけを行った。マウスドラッグ／ホイールでズームを起こしていない。

終了時に試験クライアントをdisarm・切断し、当該試験Slicerだけを終了。通常デモ画面へ戻した。
