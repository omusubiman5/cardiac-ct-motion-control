# 臨床ワークフロー（案）

## 手術前

1. 対象PC、CTビューアー、センサー、ソフトウェア版を照合する。
2. 合成または匿名化画像で全コマンドを確認する。
3. 操作担当者を登録し、カメラ画角と立ち位置を確認する。
4. 通常マウス／フットスイッチ／助手操作が利用可能であることを確認する。
5. 操作受付を無効にした状態で待機する。

## 手術中

1. 明示的な開始操作でジェスチャー受付を有効化する。
2. CTビューアーが操作対象であることを画面表示で確認する。
3. 許可されたジェスチャーを実行する。
4. システムは認識結果を表示し、該当コマンドだけを1回実行する。
5. 一定時間後、または終了ジェスチャーで受付を無効化する。

## 異常時

- 誤作動、遅延、認識不能を認めたら直ちに受付を無効化する。
- 通常の操作系へ切り替える。
- 患者安全を優先し、術中の再起動・更新・設定変更を行わない。
- 手術後にイベントIDと状況を記録し、再現試験まで運用を停止する。

## 手術後

- 操作ログとインシデント／ニアミスをレビューする。
- 患者識別情報をプロジェクト資料へ転記しない。
- 変更が必要な場合は要求・リスク・試験ケースを同時に更新する。
