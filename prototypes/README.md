# Prototypes

非臨床プロトタイプのソース、構成、ビルド手順を置く場所。

## 禁止事項

- 実患者データを含めない。
- 治療機器へ接続しない。
- 未承認プロトタイプを手術で使用しない。
- 署名、版、ハッシュを記録せず配布しない。

プロトタイプごとに、目的、対象環境、既知の制約、ビルド方法、試験結果、廃止条件をREADMEへ記載する。

## 現在のプロトタイプ

- `cmos-motion-poc/`: USB CMOSカメラ、OpenCV、MediaPipeを使い、心臓3Dモデルの回転・パン・ズーム操作量を生成するPoC。既定ではプレビューのみで、対象ウィンドウを指定しない限りWindows入力を送らない。
